HardMon — виджет мониторинга железа (портативная версия)

Запуск: распаковать в постоянную папку (например, C:\Programs\HardMon) и запустить HardMon.exe —
попросит права администратора (нужны для температуры ЦП). .NET устанавливать не нужно — всё внутри exe.
Автозапуск запоминает путь к exe: после переноса папки включите его в меню заново.

Температура ЦП требует драйвер PawnIO:
  winget install namazso.PawnIO
или установщик с https://pawnio.eu

Управление:
  - перетаскивание левой кнопкой мыши;
  - правый клик по виджету или иконке в трее — меню (компактный режим, горизонтально, размер,
    поверх окон, прозрачность, автозапуск, о программе, выход);
  - левый клик по иконке в трее — показать/скрыть.

Windows SmartScreen может предупредить при первом запуске (exe без подписи):
«Подробнее» -> «Выполнить в любом случае».
