# Changelog

## [В разработке]

### Добавлено

- Плавающий виджет (WPF, без рамки, поверх окон, перетаскивание) с мини-графиками за 60 с:
  загрузка и температура ЦП, загрузка ОЗУ, загрузка и температура дискретного GPU, занятость видеопамяти.
- Чтение датчиков через LibreHardwareMonitorLib 0.9.6; ОЗУ — через `GlobalMemoryStatusEx`.
- Самоповышение прав при запуске (нужно для температуры ЦП через драйвер PawnIO).
- Иконка в трее: показать/скрыть по клику, меню, подсказка с текущими значениями; иконка приложения `app.ico`.
- Компактный режим: только графики с короткой подписью (слева) и значением (справа) в верхних углах.
- Горизонтальный вид для компактного режима.
- Размер виджета 100 / 150 / 200% (меню виджета и трея), правый край окна при смене остаётся на месте.
- Автозапуск через Планировщик задач (наивысшие права, без ограничений по батарее и времени).
- Защита от запуска второй копии.
- Сохранение настроек (позиция, режимы, прозрачность, видимость) в `%AppData%\HardMon\settings.json`.
- Ключи `--dump`, `--no-elevate`, `--autostart on|off`.
- Скрипты `build.ps1` (сборка single-file exe в корень + перезапуск) и `make-icon.ps1`.
- Дистрибутив: установщик Inno Setup (`installer\HardMon.iss`) с опциями автозапуска и установки PawnIO,
  портативный zip; self-contained exe без зависимости от .NET; скрипт `make-release.ps1`. Версия 1.0.0.
