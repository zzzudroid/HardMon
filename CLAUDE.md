# HardMon — заметки для агента

## Дистрибутив — только портативный zip (решение от 19.10.2026)

- Установщик (Inno Setup) убран: `make-release.ps1` собирает только `release\HardMon-X.Y.Z-portable.zip`.
  Установщик не возвращать без просьбы пользователя.
- Реестр всех проектов и общих инструментов — `C:\Projects\РЕЕСТР ПРОЕКТОВ.md`.

## GitHub — только код (решение от 19.10.2026)

- Exe и zip на GitHub не загружать: ни в репозиторий, ни вложениями к Releases.
  `make-release.ps1` собирает их локально в `release\`; релиз на GitHub — только тег `vX.Y.Z`.
