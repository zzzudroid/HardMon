# HardMon

Плавающий виджет мониторинга железа для Windows в стиле мини-графиков Диспетчера задач.

Показывает (график за 60 с + значение):

- **ЦП** — загрузка, температура (CPU Package);
- **Память** — загрузка ОЗУ;
- **GPU** (дискретная NVIDIA/AMD) — загрузка, температура;
- **Видеопамять** — занятость VRAM.

Стек: C# / WPF (.NET 8), датчики — [LibreHardwareMonitorLib](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) 0.9.6, иконка в трее — WinForms `NotifyIcon`.

## Требования

- Windows 10/11, .NET 8 Desktop Runtime.
- Для температуры ЦП — права администратора и драйвер **PawnIO**: `winget install namazso.PawnIO`.
  Без них виджет работает, но плитка «Темп. ЦП» пустая.

## Запуск

- `HardMon.exe` в корне проекта — двойной клик (запросит UAC и перезапустится с правами админа).
- Автозапуск — пункт меню «Запускать при входе в Windows»: создаёт задачу Планировщика `HardMon`
  с наивысшими правами (без UAC при входе, работает и от батареи, без лимита времени).

## Управление

- Перетаскивание — левой кнопкой мыши.
- Правый клик по виджету или по иконке в трее — меню: скрыть/показать, **компактный режим**
  (только графики с подписью и числом в углах), **горизонтально** (в компактном режиме),
  поверх всех окон, прозрачность, автозапуск, выход.
- Левый клик по иконке в трее — показать/скрыть виджет; подсказка иконки — текущие значения.
- Настройки сохраняются в `%AppData%\HardMon\settings.json`.

## Сборка

```powershell
.\build.ps1
```

Закрывает запущенный виджет (UAC), публикует single-file exe и кладёт `HardMon.exe` в корень,
затем перезапускает виджет. Иконка `app.ico` генерируется скриптом `.\make-icon.ps1`.

## Отладка

`HardMon.exe --dump` — записать все датчики в `sensors.txt` рядом с exe.
Прочие ключи: `--no-elevate` (не запрашивать права), `--autostart on|off`.
