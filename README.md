# HardMon

Плавающий виджет мониторинга железа для Windows в стиле мини-графиков Диспетчера задач.

Показывает (график за 60 с + значение):

- **ЦП** — загрузка, температура (CPU Package);
- **Память** — загрузка ОЗУ;
- **GPU** (дискретная NVIDIA/AMD) — загрузка, температура;
- **Видеопамять** — занятость VRAM;
- **Интернет ↓** — скорость приёма: всего, через VPN (тёмно-зелёная часть графика) и напрямую (ярко-зелёная, «матричная»).
  Неоновый значок «VPN» в углу графика горит зелёным, когда интернет идёт через VPN, жёлтым — когда VPN
  подключён, но интернет идёт мимо него (split-tunnel), и тусклый — когда напрямую.
  Разбивка «VPN / напрямую» в цифрах — во всплывающей подсказке плитки.

Как считается сеть: счётчики интерфейсов `GetIfTable2`. Физические — реальные сетевые карты
(без фильтров NDIS, Hyper-V/WSL и WAN Miniport), туннельные — адаптеры OpenVPN (DCO, TAP-Windows),
WireGuard/AmneziaWG, Wintun, а также любой виртуальный адаптер (тип `IF_TYPE_PROP_VIRTUAL`), через который
идёт маршрут в интернет — так распознаются Shadowsocks/V2Ray/Clash/sing-box в режиме TUN и прочие клиенты
с нестандартным именем адаптера. Зашифрованный трафик VPN физическая карта тоже видит, поэтому
«напрямую» = физический − туннель − 76 байт оверхеда на пакет туннеля (замер на OpenVPN Connect).
Режим значка — по `GetBestInterface` до 1.1.1.1: через какой интерфейс реально уйдёт пакет.
Ограничения: локальный трафик (NAS в той же сети) считается как «напрямую»; VPN в режиме прокси
(без своего адаптера — Shadowsocks в режиме «системный прокси») не распознаётся; для TUN-клиентов
с неизвестным именем адаптера режим split-tunnel (жёлтый) не показывается — только «через VPN» или «напрямую»;
у прокси-туннелей (Shadowsocks и пр.) пакеты не 1:1 с внешними, поэтому разбивка «VPN / напрямую» приблизительная;
маршрут проверяется только для IPv4.

Стек: C# / WPF (.NET 8), датчики — [LibreHardwareMonitorLib](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) 0.9.6, иконка в трее — WinForms `NotifyIcon`.

## Установка

На GitHub лежит только исходный код — готовые exe и установщики туда не выкладываются.
Установщик и портативная версия собираются локально скриптом `.\make-release.ps1` (см. [Релиз](#релиз)):

- **`HardMon-Setup-x.y.z.exe`** — установщик: Program Files, ярлык в «Пуске», галочки «автозапуск»
  и «установить PawnIO» (для температуры ЦП). Удаление — через «Приложения» Windows.
- **`HardMon-x.y.z-portable.zip`** — один exe без установки.

.NET ставить не нужно — runtime встроен в exe. Exe не подписан, поэтому SmartScreen при первом запуске
может предупредить: «Подробнее» → «Выполнить в любом случае».

## Требования (для разработки)

- Windows 10/11, .NET 8 Desktop Runtime.
- Для температуры ЦП — права администратора и драйвер **PawnIO**: `winget install namazso.PawnIO`.
  Без них виджет работает, но плитка «Темп. ЦП» пустая.

## Запуск

- `HardMon.exe` в корне проекта — двойной клик (запросит UAC и перезапустится с правами админа).
- Автозапуск — пункт меню «Запускать при входе в Windows»: создаёт задачу Планировщика `HardMon`
  с наивысшими правами (без UAC при входе, работает и от батареи, без лимита времени).

## Управление

- Перетаскивание — левой кнопкой мыши.
- Правый клик по виджету или по иконке в трее — меню: скрыть/показать, **компактный режим**
  (только графики с подписью и числом в углах), **горизонтально** (в компактном режиме),
  **размер** 100/150/200%, поверх всех окон, прозрачность, автозапуск, **о программе** (версия и ссылка на GitHub), выход.
- Левый клик по иконке в трее — показать/скрыть виджет; подсказка иконки — текущие значения.
- Настройки сохраняются в `%AppData%\HardMon\settings.json`.

## Сборка

```powershell
.\build.ps1
```

Закрывает запущенный виджет (UAC), публикует single-file exe и кладёт `HardMon.exe` в корень,
затем перезапускает виджет. Иконка `app.ico` генерируется скриптом `.\make-icon.ps1`.

### Релиз

```powershell
.\make-release.ps1
git tag vX.Y.Z; git push origin vX.Y.Z
```

Файлы из `release\` остаются локально (папка в `.gitignore`) и на GitHub не загружаются — передавать их напрямую.
Версия — `<Version>` в `HardMon.csproj`. Скрипт собирает self-contained exe, скачивает `PawnIO_setup.exe`
(вкладывается в установщик), собирает установщик Inno Setup (`installer\HardMon.iss`) и портативный zip в папку `release\`.
Inno Setup — общий для всех проектов: Inno Setup 7 в `%LOCALAPPDATA%\Programs\Inno Setup 7\ISCC.exe`.
Свою копию в проект не ставить.

## Отладка

`HardMon.exe --dump` — записать все датчики и сетевые интерфейсы (с замером скорости за 1 с) в `sensors.txt` рядом с exe.
В сетевой части — все интерфейсы, включая отброшенные (`Other`), с типом, флагами и статусом, интерфейс маршрута
до 1.1.1.1 и системный прокси. Если не горит значок VPN — снять дамп с включённым и выключенным VPN и сравнить.
Прочие ключи: `--no-elevate` (не запрашивать права), `--autostart on|off`.
